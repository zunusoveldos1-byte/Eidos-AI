# Исправления 14 октября 2026

Падение Vosk `starting → loading` воспроизведено регрессионным тестом.
Потоковый движок готовит модель **до** открытия микрофона, поэтому разрешены
`starting → loading → recording`. Whisper сохраняет прежний порядок.
После потоковой записи worker теперь явно сообщает `transcribing` перед
финализацией, обработкой команды и синтезом; иначе следующий переход к
`synthesizing` тоже мог завершить приложение. Отмена возвращает в idle,
следующая запись проходит ту же последовательность.

Сброс настроек больше не возвращает скрытого нижнего персонажа: сохраняются
его видимость, режим размещения, положение и always-on-top. Остальные настройки
возвращаются к исходным значениям. Регрессионный тест до исправления падал,
после исправления проходит.

Светлая тема теперь различает foreground/background/border при построении QSS;
иконки заголовков получают тёмный цвет. Главный экран с собственными тёмными
рисующими виджетами сохраняет согласованную исходную палитру. Геометрия не менялась.
