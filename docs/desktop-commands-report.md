# Системные команды Eidos — 14 октября 2026

Встроено в существующий PyQt6/AgentService/VoiceWorker, без отдельного приложения
и без замены темы, навигации или визуальной концепции. В существующем разделе
«Инструменты → Windows и браузер» доступны текст команды, кнопка выполнения,
полный ответ и выбор папки скриншотов. Голос использует тот же AgentService.

## Реализовано

- Локальный разбор перечисленных в ТЗ команд: скриншоты, громкость/mute,
  рабочий стол, блокировка, питание, сайты/поиск, Steam/Spotify/приложения,
  сохранение/восстановление сессии, задачи/локальное расписание.
- Числа цифрами и русскими словами; установка и изменение громкости различаются.
  Изменение по умолчанию 10 процентных пунктов, clamp 0–100. Core Audio получает
  актуальный endpoint на каждом вызове. Unmute не меняет уровень.
- Отрицания и вопросы о действии не исполняются. Неизвестная команда остаётся
  в существующем помощнике; LLM имеет только валидируемые схемы инструментов.
  Питание не предоставлено модели как исполняемый инструмент.
- Скриншот основного монитора или композиция виртуального рабочего стола
  копируются в Windows clipboard через Qt GUI-поток. Композиция учитывает
  отрицательные координаты и смешанный DPI, используя общую шкалу max DPR.
  Ничего не сохраняется на диск без отдельной команды «Сохрани скриншот».
  Сохранение не разрешено в схеме скриншота LLM.
- Область вызывает `ms-screenclip:`. Ответ о копировании появляется только после
  появления нового изображения в буфере. Отмена запроса прекращает ожидание;
  если системное выделение закрыто Esc без результата, ожидание истекает через
  60 секунд с сообщением об отмене/отсутствии изображения. Синтетические проверки
  этого lifecycle прошли; реальная ручная выборка области мышью не выполнялась.
- Рабочий стол использует Shell.MinimizeAll, не переключатель Win+D.
  [API Microsoft](https://learn.microsoft.com/en-us/windows/win32/shell/ishelldispatch-minimizeall).
  Блокировка — LockWorkStation.
- Питание требует текущего подтверждения «Подтверждаю выключение/перезагрузку»
  или кнопки. Неблокирующий компактный диалог закрывается через 15 секунд.
  Чужое/просроченное подтверждение не выполняется; «Отмена» отменяет ожидающее
  действие, включая голос во время ответа. Сам голос TTS не подтверждает питание:
  фразы, начавшиеся во время воспроизведения, не исполняются как обычные команды.
  Стоп микрофона остаётся отдельным локальным намерением.
- Перед питанием атомарно сохраняется сессия. Windows получает фиксированный
  shutdown.exe `/s` или `/r`, `/t 0`, без `/f`. Несохранённые приложения могут
  остановить завершение. Для `/t > 0` Windows подразумевает force, поэтому такой
  таймаут не используется. [Документация Microsoft](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/shutdown/).
- Сайты открываются через системную обработку HTTP/HTTPS, без DNS-проверки,
  запуска shell или передачи речи в командную строку. YouTube/GitHub/Google
  имеют алиасы; неизвестный адрес требует корректного домена. Поиск кодирует
  запрос URL-параметром. Новая установка использует Google; прежний выбор
  поисковика сохраняется.
- Каталог приложений использует пользовательские EXE, App Paths в HKCU/HKLM
  (32/64-bit), ограниченный обход ярлыков Start Menu и зарегистрированные
  steam/spotify URI. Кэш 5 минут; весь диск не сканируется. Неизвестному
  приложению один раз предлагается выбрать EXE, привязка сохраняется.
  Имеющее окно приложение активируется по возможности. Steam web helpers
  связываются с главным steam.exe. Ответ «Запускаю…» подтверждает запрос,
  а не появление окна.
- SessionStore сохраняет только приложения с видимыми именованными окнами,
  исключая PID Eidos, известные оболочки/служебные процессы и установщики.
  JSON: version, updated, applications[{name,path}], без заголовков окон,
  аргументов процессов, токенов, документов и вкладок. Атомарная staging+replace.
  Снимок обновляется при изменениях каждые 15 секунд, по явной команде,
  при завершении Eidos и перед питанием. WM_QUERYENDSESSION/WM_ENDSESSION/
  suspend запрашивают дополнительное асинхронное сохранение; периодические
  снимки остаются страховкой при быстром завершении Windows.
- Восстановление проверяет EXE, дедуплицирует, пропускает уже открытое,
  запускает последовательно с интервалом 150 ms и продолжает после отсутствующего
  приложения. Отмена/таймаут не выдаются за успешное завершение.
- Реальные локальные задачи хранятся в SQLite отдельно от календарных событий.
  «Добавь задачу [название] на сегодня» создаёт задачу; просмотр различает сегодня
  и просроченные, исключает завершённые, использует timezone настроек.
  Первые предложения — краткая озвучка, полный список остаётся в области ответа.
  При brief=False пользователь явно предпочёл полную озвучку.
- `Tasks.connect_provider(provider)` — интерфейс внешнего источника с `fetch()`,
  name/connected. Данные кэшируются в SQLite и доступны после перезапуска с
  отметкой «Сохранённые данные». Различаются пустой список, неподключённый
  источник и временная недоступность без кэша. Google Tasks OAuth не настроен,
  интеграция не выдаётся за подключённую и демонстрационные задачи не создаются.
  «Покажи расписание» показывает существующий локальный календарь с явной
  отметкой отсутствия внешней синхронизации.

таймаута и helper-процессов — 374 passed in 80.03s. Финальные результаты ниже.
Окончательный общий набор: **377 passed in 78.60s**. После уточнения отрицательных/
дробных чисел и защитного интервала TTS: **52 passed in 4.29s** для затронутого

clipboard проверяется по фактическому завершению, без жёсткой привязки к 120 ms.
Проверки покрывают русские числа, отрицания, схемы/URL, 15-секундное питание,
отмену, атомарную сессию, отсутствие аргументов, дедупликацию/уже открытое,
продолжение после ошибки, кэш задач, ожидание clipboard и Core Audio endpoint.
Питание и блокировка не исполнялись реально: используются fake backend и
подменённый subprocess; argv отдельно проверяется на отсутствие `/f`.

## Ограничения и запуск

Каталог не гарантирует распознавание всех UWP-приложений и чужих launcher/helper
архитектур. Их безопасная привязка требует приложения/протокола, поддерживающего
восстановление; неизвестные записи пропускаются. Список EXE не восстанавливает
документы, браузерные вкладки или несохранённые данные. Внешние Google Tasks/
календарь требуют настроенного OAuth-провайдера; сейчас их нет.

Перезапустите `.\.venv\Scripts\python.exe -m eidos`. Текстовые команды:
«Инструменты → Windows и браузер». Голос — существующая кнопка микрофона.
Примеры: «Сделай скриншот», «Установи громкость на сорок процентов»,
«Гугли Python asyncio», «Сохрани сессию», «Восстанови сессию»,
«Добавь задачу проверить отчёт на сегодня», «Покажи задачи на сегодня».
