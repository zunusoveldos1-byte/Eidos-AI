## Голос и архитектура

`VoiceController → VoiceWorker → LocalSTT` совместимы с прежними интерфейсами.
Faster-Whisper остаётся по умолчанию. Vosk 0.3.45 доступен как отдельная опция,
с ленивой загрузкой локальной модели и потоковой обработкой PCM16.
При переключении движка освобождается предыдущий; две модели не удерживаются
намеренно одновременно. Whisper использует только существующий локальный кэш;
скрытая загрузка модели при голосовом запросе исключена.

В audio callback нет распознавания. Он передаёт ограниченные порции в очередь
на 32 элемента; worker выполняет обработку. Потеря аудиоданных даёт явную ошибку.
Потоковый режим не склеивает и не преобразует всю запись повторно после записи.
Есть отмена между блоками/сегментами, ограничение времени, очистка callback и
освобождение потоков/микрофона при завершении. В закрывающемся окне журнал уже
не обновляет QTextDocument; файловый лог остаётся.

На Windows Vosk обнаружена проблема пути с кириллицей. Для тех же файлов
используется ASCII short path NTFS. Если короткий путь недоступен, показывается
причина и требуется каталог модели без кириллицы; файлы не копируются незаметно.

Детерминированные команды проходят прежние разрешения. Добавлено распознавание
словесных значений громкости 0–100; неоднозначные числа не выполняются напрямую.
Метрики содержат только времена: wake_detection, audio_buffering, model_load,
stt, command_routing, llm_first_token, tts и дополнительные stt_chunk/finalization.
Буфер метрик ограничен 256 отсчётами; диагностический отчёт показывает p50/p95.

Оборудование проверено: RTX 3050 Laptop, **6144 MiB VRAM**, 12 логических CPU,
15,73 GiB RAM. STT сравнивался на CPU/int8, GPU для STT не использовался.

Это моментальный показатель всей системы, а не пик памяти конкретного движка.

Одинаковый корпус: 6 русских фраз Windows SAPI, чистый звук и добавленный шум,
два повторения: **24 прогона на движок**. Команды не выполнялись. Baseline взят

## Запуск и конфигурация

Из рабочей папки в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m eidos
```

Голосовые параметры: **Настройки → Голос → Устройство и голос**.
Whisper требует заранее подготовленного локального кэша модели. Имеющийся
HF-кэш base используется без скачивания. Смена выбора не загружает модель сама.

Vosk уже установлен в этой `.venv`. Модель для проверки подготовлена в:
`C:\Users\Элдос\Desktop\Eidos\.cache\voice-models\vosk-model-small-ru-0.22`.
Выберите Vosk и этот каталог в настройках, сохраните. Для нового окружения:

```powershell
.\.venv\Scripts\python.exe -m pip install ".[voice,vosk,agent]"
.\.venv\Scripts\python.exe scripts\prepare_vosk_model.py
```

Последняя команда — **явная загрузка**, а не действие startup/voice. Загрузчик
ограничивает архив 80 MB, распаковку 200 MB, общее время 360 секунд, проверяет
границы ZIP и фиксирует наблюдаемый SHA256. Этот SHA256 не является подписью
издателя. Пакет Vosk фиксирован на 0.3.45; модель — small-ru-0.22.

Активация: **Настройки → Голос → Активация голосом**. Нужны pvporcupine,
AccessKey, совместимый Windows keyword `.ppn` и языковой `.pv`.
При отсутствии компонента показывается конкретная причина. Реальная работа wake
без этих ресурсов не заявляется. Для установки пакета в новом окружении:
`python -m pip install ".[wake]"` в выбранной `.venv`.

Для полностью локальной озвучки выберите Windows SAPI. Edge, Google, OpenAI
являются внешними сервисами; их назначение указано в UI, перед текстом применяется
фильтр. Ограничения сети показываются как ошибка, операцию можно повторить.
Фильтр шаблонов/известных значений не является гарантией обнаружения любого
неизвестного секрета.

Повтор проверки:

```powershell
$env:QT_QPA_PLATFORM='offscreen'
$env:TEMP=(Resolve-Path '.cache').Path
$env:TMP=$env:TEMP
.\.venv\Scripts\python.exe -m pytest -q --basetemp=.cache/pytest-local
.\.venv\Scripts\python.exe scripts\verify_modernization.py
.\.venv\Scripts\python.exe scripts\benchmark_voice_stages.py --output .cache/voice-comparison.json
.\.venv\Scripts\python.exe scripts\benchmark_local_response.py
```

Windows sandbox может блокировать asyncio socketpair/Qt IPC; итоговые проверки
проведены вне него на синтетических данных. Скрипты переводов — только инструменты
разработчика: local proposals пишутся в `.cache/catalog-proposals`, сетевой helper
заполняет только отсутствующие ключи. Они не импортируются приложением.

## Ограничения и источники

Нативная модель STT не прерывается принудительно внутри одного вызова C++;
отмена и deadline проверяются между сегментами/порциями. Скачивания не происходят
при распознавании. Повреждённая SQLite отклоняется без пересоздания/удаления;
автоматическое восстановление повреждённых пользовательских данных не добавлено.
Переводы машинные с технической проверкой; редактура носителями кыргызского,
узбекского и казахского остаётся полезной. Произвольные сообщения сторонних
библиотек и родные названия оборудования не имеют гарантированного перевода.
Светлая тема изменяет общий UI; оригинальная иллюстрация и декоративная палитра
главного/голосового экрана сохраняются.

«Rust Potter» подтверждён как [Rustpotter](https://github.com/GiviMAD/rustpotter)
и [rustpotter-cli](https://github.com/GiviMAD/rustpotter-cli): Rust wake detector,
а не полноценный STT. Поддерживаемый Python binding 3.11/3.12 не подтверждён;
Windows CLI есть, но измеренного выигрыша нет. Компонент не установлен/не внедрён.

Context7 реально использован: сначала resolve, затем query для PyQt6/Qt 6,
Vosk, Faster-Whisper, Porcupine и Ollama. Дополнительные официальные источники:
[Windows Run](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys),
[GetShortPathNameW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getshortpathnamew),
[Vosk models](https://alphacephei.com/vosk/models).
