# Eidos MVP — проектное решение

Назначение: русскоязычный настольный ассистент Windows 10/11, Python 3.11.
На первом этапе работает только запуск голосового цикла кнопками.

UI PyQt6 управляет QObject-worker в QThread через сигналы. Worker последовательно
открывает sounddevice InputStream, накапливает float32 mono в памяти, закрывает
микрофон, загружает Faster-Whisper и распознаёт русский текст. Затем чистый
обработчик команд формирует ответ. Синтез edge-tts выполняется в asyncio loop
worker-потока; QtMultimedia воспроизводит временный MP3 в GUI-потоке.

Запись ограничена 120 секундами для защиты памяти. Используется частота устройства;
перед STT выполняется преобразование в 16 кГц. Настройки JSON записываются атомарно
в LOCALAPPDATA/Eidos. Whisper base/CPU/int8, fallback float32 по доступным compute
types. Загрузка сначала проверяет локальный кеш, при отсутствии сообщает об интернете.

Повторные действия блокируются состояниями. Закрытие устанавливает threading.Event,
закрывает микрофон в worker и ждёт окончания текущего нативного вызова, сохраняя
отзывчивость окна. QThread не уничтожается и не terminate-ится во время работы.
Пустая запись, ошибка устройства/модели/TTS приводят к понятному статусу и дают повторить.
Данные речи не попадают в файловый журнал. MP3 удаляется после воспроизведения/ошибки.

Vision/OCR и будущий LLM имеют Protocol-интерфейсы и отключённые реализации.
Их библиотеки не устанавливаются. Автотесты используют подмену аудио/STT/TTS,
проверяют команды, настройки, переходы, ошибки и завершение worker; реальные
модели и микрофон в unit-тестах не используются.
