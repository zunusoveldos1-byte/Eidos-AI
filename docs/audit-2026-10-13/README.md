# Результаты аудита Eidos — 13 октября 2026

Начните с [полного отчёта](<C:/Users/Элдос/Desktop/Eidos/docs/project-audit-2026-10-13.md>). Он объясняет назначение, фактическую конфигурацию, архитектуру, границы функций, приватность, уязвимые места и порядок следующих работ.

Основные результаты:

- Eidos запускается, wheel собирается, итоговый полный прогон: **280 passed**.
- Локальная Qwen работает через Ollama и загружается в GPU; текущий контекст **2048**, Whisper base работает на CPU.
- Перевод отправляет распознанный текст Google; стандартная озвучка использует Edge TTS. Выявлен пробел в фильтрации секретов до запроса перевода.
- Активация словом включена в настройках, но пакет Porcupine и файлы моделей не готовы.
- Проверка **36 публичных библиотек** по OSV не выявила известных advisories для установленных версий. Это ограниченный version lookup, а не проверка всех компонентов.
- JARVIS — отдельный проект, не включён в wheel Eidos. Его runtime, опасные пути исполнения и proprietary-лицензия требуют отдельного внимания.
- Один полный тестовый прогон завис на закрытии Qt-окна; отдельный тест и последующий полный прогон прошли. Стек сохранён, причина не установлена.

`checks/` содержит логи и JUnit XML. `evidence.json` содержит технический снимок и искусственные проверки политик. `local-model-probe.json` содержит два новых измерения модели. `dependency-advisories.json` содержит результат OSV. Другие JSON описывают окружение, состав wheel и репозиторий.

В ходе аудита добавлены документы и диагностические скрипты. Производственный код и пользовательские настройки не изменялись. Скрипты сохраняют собственные результаты и искусственные файлы; повторный запуск обновляет evidence. `--osv` отправляет только названия/версии фиксированного списка публичных библиотек. Проверка модели отправляет только искусственные запросы в локальный Ollama и не исполняет предложенные инструменты.
