# Eidos: фактическое состояние и дальнейшие работы

Срез кода от 11 октября 2026. «Работает» ниже означает реализованную возможность с локальными проверками; наличие микрофона, установленной модели, внешнего сервиса и ключей проверяется отдельно на компьютере пользователя.

## Что работает

- Восемь разделов: Главная, Диалог, Голос, Экран и перевод, Камера и жесты, Инструменты, Память, Настройки. Формы памяти, модели, подключений и календаря перенесены, а не продублированы.
- Один персонаж, переносимый между выделенной полосой приложения и прозрачным настольным окном. Клик, drag, клавиатура, контекстное меню, положение, скрытие и закрепление; общий контроллер записи, задач и проигрыватель.
- Развёрнутый обычный запуск Windows; независимая настройка запуска в трее. Отсутствие трея приводит к показу окна.
- Голосовой ввод, локальный Whisper, простой разбор команд Windows, ответ через агент, очередь Edge/SAPI и отмена. Одна операция записи сохраняется при переносе персонажа.
- Диалог и вложения; постоянная SQLite-память с поиском, исправлением и удалением; отдельные пользовательские профили. Это сведения и предпочтения, не обучение весов и не проверка личности.
- Явное выделение области экрана, локальный OCR, исправление текста, Google-перевод, overlay, озвучка. OCR и перевод проходят через общий Registry/TaskContext. Объяснение выбранного текста использует существующий агент; текст считается недоверенными данными.
- Разрешённые приложения Windows, звук, открытие URL, чтение публичных страниц, выбранные документы TXT/MD/DOCX/XLSX/PDF, создание новой версии и локальный календарь с напоминаниями, пока открыт Eidos.

## Частично реализовано

- Активация «Эйдос» требует Porcupine, AccessKey и моделей .ppn/.pv. Режим имеет ограничения устройства, шума и прерывания; нужна серия проверок на реальном микрофоне.
- Ответы модели зависят от доступного Ollama-сервера или выбранного облачного провайдера. Диалог/инструменты проверены с тестовыми ответами; реальная модель не запускалась в рамках интерфейсного прогона.
- Камера: явный локальный предпросмотр QtMultimedia и освобождение устройства. На этой машине Qt не обнаружил камеру; проверка start/stop сделана с подменой устройства. Сцена не анализируется.
- Telegram/Discord: существующие официальные bot-адаптеры, списки разрешённых пользователей/каналов и подтверждение отправки. Настройка реальных ботов, ключей и прав сервера не выполнена.
- Кадры персонажа очищены встроенным imagegen, фон прозрачный, сетка и масштаб согласованы. Это рабочая последовательность, а не готовая студийная анимация; художественную стабильность контуров/масштаба стоит проверить вручную.

## Чего нет

Распознавание жестов, проверка личности, понимание сцены камеры/изображений, постоянное наблюдение за экраном, синхронизация календаря, полноценное управление вкладками браузера, сохранение оформления редактируемого документа и автономный запуск произвольного кода. Текущие адаптеры модели передают текст; передача изображения не подключена даже при выборе модели с потенциальной поддержкой vision.

## Подключения и границы данных

| Возможность | Требуется | Обработка |
|---|---|---|
| Распознавание речи | Микрофон, sounddevice, локальные веса Whisper | Локально после загрузки весов |
| Озвучка | Установленный голос SAPI либо Edge | SAPI локально; Edge получает текст ответа |
| Активация словом | Porcupine, AccessKey и Windows/языковые модели | Обнаружение слова локально; требования SDK/ключа отдельные |
| Диалог и tool calling | Запущенный Ollama с подходящей текстовой моделью либо облачный API и ключ | Ollama — на заданном сервере; OpenAI получает запрос и выбранный контекст |
| OCR/перевод | Локальный OCR; сеть для Google | Изображение остаётся локальным; Google получает распознанный/введённый текст |
| Камера | Устройство, драйвер и QtMultimedia | Только локальный предпросмотр, без записи/отправки |
| Источники из поиска | Интернет; для автоматических результатов — настроенный Brave API | Запрос уходит выбранному поисковику |
| Боты | Токены, явные allowlists, права канала | Текстовые bot API; внешняя отправка с подтверждением |

## Порядок развития

| Приоритет / функция | Конкретный сценарий | Зависимости | Критерий готовности |
|---|---|---|---|
| 1. Надёжный разговор | «Эйдос, открой блокнот», затем ещё одна команда без потери начала фразы | Реальный микрофон, Whisper, VAD/активация | Серия 30 команд в тишине и шуме; отсутствие двойного захвата; команда отменяется и запись возобновляется |
| 1. Простые команды и подтверждение результата | Изменить громкость и проверить фактическое значение | Windows Core Audio, общий harness | Успех сообщается только после обратного чтения; ошибка/отмена не становятся успешным ответом |
| 2. История диалогов | Найти вчерашний разговор и продолжить его отдельной беседой | Схема бесед/сообщений и миграция SQLite | Можно открыть/переименовать/удалить беседу; incognito ничего не сохраняет |
| 2. Полезная память | «Мой проект использует Python», затем исправить сохранённый факт | UI памяти, источники, фильтрация секретов | Каждая запись имеет источник; исправление применяется в следующем ответе; удалённые записи не извлекаются |
| 3. Объяснение области | Выделить ошибку в приложении и получить пояснение по OCR-тексту | Реальная модель с tool calling; текущий OCR | Ответ опирается на извлечённый текст и помечает сомнительное распознавание; инструкции из снимка не исполняются автоматически |
| 3. Изображения, диаграммы | Выделить диаграмму без текста и задать вопрос о ней | Новый vision-адаптер, совместимая модель, явная передача снимка | Пользователь видит выбранный снимок и место обработки; тесты доказывают, что остальной экран не отправляется |
| 3. Постоянный анализ — отдельно | Добровольно следить за изменениями одной области | Явный переключатель, индикатор, лимиты частоты и хранения | По умолчанию выключен; видимый индикатор; отключение прекращает захват; нет анализа всего экрана без выбора |
| 4. Документы с сохранением структуры | Исправить абзац DOCX, сохранив оформление и таблицы | Структурный редактор документа и проверка результата | Исходник сохранён; новая версия имеет нужное изменение и прежние стили; сравнение доступно до записи |
| 4. Работа в браузере | Прочитать выбранную вкладку и подготовить краткое изложение | Адаптер конкретного браузера, доступ к выбранной вкладке | Источник и вкладка указаны; приватные вкладки/авторизация не затрагиваются без выбора |
| 4. Внешний календарь | Создать встречу и увидеть её у выбранного провайдера | Официальный календарный API, OAuth, часовые пояса | Создание/изменение/удаление сверяется с API; повторный запрос не дублирует событие |
| 5. Один полезный жест | Открытой ладонью поставить озвучку на паузу | Детектор руки, калибровка и задержка повторов | Только после включения; без случайных переключений; выключение освобождает камеру |
| 5. Вопрос по кадру камеры | Сделать явный снимок предмета и спросить о нём | Захват одного кадра и vision-адаптер | Отправляется только выбранный кадр; предположения помечены; нет заявлений о проверке личности |
| 6. Для программиста | Выбрать лог ошибки и получить объяснение + патч | Текстовая модель, выбранные файлы, обзор патча | Изменения доступны для просмотра; код не запускается без отдельного действия |
| 6. Для дизайнера | Выбрать экран и получить замечания о читаемости | Vision либо явно доступный текст/layout-контекст | Замечания ссылаются на фактически переданный экран; нет придуманных элементов |
| 6. Для студента | Прочитать выбранный PDF и составить план повторения | Извлечение текста/OCR сканов, модель, локальные события | Каждая тема связана с документом; сканы не объявляются прочитанными без OCR |
| 7. Telegram / Discord | Получить команду от разрешённого пользователя и ответить после подтверждения | Реальные токены, allowlists, права бота, журнал доставки | Проверены обе allowlists; повторная доставка не повторяет действие; вложения/локальные данные не раскрываются |

Наибольшую пользу сначала дадут стабильный голос, продолжение диалогов и объяснение выбранного OCR-текста. Новые камеры, автономные действия и внешние интеграции стоит добавлять только после проверки этих сценариев на реальных устройствах.
