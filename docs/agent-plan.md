# Развитие Eidos в персонального ассистента

1. Диагностика без идентификаторов; Ollama / опциональный OpenAI-провайдер,
   Qwen3 4B Instruct 2507 Q4_K_M, 4096 токенов, GPU; запасной 1.7B / 2048.
2. Ограниченный реестр инструментов, проверка аргументов и результата,
   явные подтверждения изменений, отмена, дедлайн, безопасный retry.
3. Отдельная страница ассистента с вкладками: диалог, память, skills,
   подключения, модель, профиль. SQLite FTS5 и необязательный onboarding.
4. Выбранные файлы, документы, публичные страницы, локальный календарь
   с часовым поясом и напоминаниями. Новые версии вместо перезаписи.
5. Официальные Telegram / Discord bot API, Credential Manager, закрытые
   списки доступа, запрет удалённых Windows-инструментов по умолчанию.

Проверки: существующий voice/UI, fake model tools, валидация, отмена,
подтверждения, FTS/удаление, изоляция удалённых запросов, отсутствие retry
отправки, реальные ответы / tool calls локальной модели, снимки экранов.
Микрофон без действия пользователя не включать. Внешние bot/API проверки
без пользовательских токенов не считать состоявшимися.
