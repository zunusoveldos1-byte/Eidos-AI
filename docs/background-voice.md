# Фоновый голос и перевод — 10 октября 2026

## Использование

Запуск из корня проекта:

```powershell
& .\.venv\Scripts\python.exe -m eidos
```

Настройки → Голос в фоне: включите скрытие в трей и плавающий маскот при
необходимости. По умолчанию крестик по-прежнему завершает приложение.
Ctrl+Alt+V начинает запись; повторное нажатие завершает запись. Во время
озвучки новая команда отменяет предыдущую речь. Микрофон выключен до явного
действия или отдельно включённого wake-word. Меню трея открывает окно,
начинает ввод, приостанавливает/возобновляет микрофон, останавливает речь и
завершает приложение. «Выход» ждёт голосовой, агентский, OCR и speech workers.

Плавающий маскот перемещается мышью, сохраняет положение в логических
координатах и возвращается в доступную область после изменения экранов.
Кнопка стоп останавливает запись/операцию/озвучку. Анимация «говорит» общая,
без lip-sync; уровень «слушает» берётся из реальных samples. Уменьшенные
анимации отключают визуальные timers. На скрытых маскотах они также выключены.

## Голосовые технологии

STT остаётся локальным Faster-Whisper. Ответы используют прежний harness,
разрешения, профиль и память. Полный текст остаётся на экране; spoken text
очищен от Markdown, code blocks, URL и содержит до трёх предложений в кратком
режиме. Длинная речь разбита на последовательные предложения с ограниченной
очередью, отменой и одним QAudioOutput.

Edge TTS — онлайн, русский голос Светлана/Дмитрий, реальный rate. Громкость
управляется общим проигрывателем, а не дважды через провайдер и output.
Локальный Windows SAPI использует установленные голоса; «Найти голоса Windows»
перечисляет их в worker. На этом компьютере доступны Ирина (русский) и Zira
(английский). Большая TTS-модель не загружалась. Выберите провайдер и голос,
скорость, громкость; «Прослушать пример» позволяет проверить черновые значения.
Эмоциональная речь и пользовательский SSML не заявляются.

Porcupine optional: `python -m pip install -e ".[wake]"`. Нужны ваш AccessKey,
Windows-модель Eidos `.ppn` и подходящая языковая `.pv` из Picovoice Console.
Включите активацию отдельно. Ключ сохраняется только в Windows Credential
Manager (сервис Eidos/assistant, porcupine_access_key); в config.json только
переключатель и пути. Пустое поле и «Сохранить ключ отдельно» удаляют ключ.
При отсутствии пакета, ключа или файлов обычный голос остаётся доступен.

Постоянный поток используется лишь локальным детектором слова. После него
записывается команда: pre-roll 0,3 с, ожидание начала до 5 с, конец после
0,8 с тишины, максимум 30 с. Это локальный порог RMS, не полноценный speech
classifier; в шумной комнате возможны неточные границы. Ручная запись
сохраняет лимит 120 с. Во время обработки и TTS wake-word освобождает микрофон,
возобновляется после завершения с паузой 0,4 с. Голосовое перебивание без AEC
не включено. При отказе микрофона режим не перезапускается бесконечно.

## Подключение JonSnow

Python/PyQt6-код уже объединён в main. `JonSnowTranslator` в
`eidos/modules/ocr/interface.py` делегирует существующим ScreenOCR/WindowsOCR
и OnlineTranslator; workers вызывают адаптер. Захват остаётся локальным,
OCR использует Windows или Tesseract. Google получает только распознанный
текст. На странице есть выбор Google/без сети, отмена, копирование,
озвучивание общей очередью и прежние Ctrl+Alt+T/R/X. Провайдер «без сети»
не отправляет текст. Это не реализованный офлайн-переводчик.

Маскот временно скрывается при захвате и восстанавливается после выбора,
отмены/ошибки. Прежний слой перевода скрывается до нового результата;
при отмене возвращается. DPI и логика нескольких мониторов JonSnow сохранены.
Сброс настроек синхронизирует языки и переключатель слоя с UI.

Атрибуции исходного модуля и Inter OFL сохранены. Tesseract — Apache-2.0,
Python-обёртка tesserocr — MIT, Pillow — MIT-CMU; winrt-runtime — MIT (см. metadata/лицензии установленных
пакетов). Условия Windows-голосов зависят от установленной Windows;
Porcupine AccessKey и модели используются по условиям Picovoice.

## Фактические проверки

- 148 тестов прошли в финальном offscreen-прогоне; 147 прошли с Windows Qt
  до добавления проверки HTTP 429. Проверены прежний агент/голос/перевод,
  очередь речи, отмена и late file cleanup, wake prerequisites и handoff с
  fake-движком, RMS и конец по тишине, tray lifetime, reset, reduced animation,
  сохранение слоя, отказ сети без provider и ошибки после отмены.
- compileall и pip check успешны.
- `scripts/check_background_native.py`: настоящий Windows Qt и доступный трей;
  скрытие оставляет голосовой worker работающим, explicit exit завершает
  voice/agent/speech и снимает hotkeys. RegisterHotKey действительно зарегистрирован;
  собственное WM_HOTKEY доставлено через Windows event loop при скрытом окне.
  Физическое нажатие пользователем комбинации не проверялось.
- `scripts/check_speech_native.py`: SAPI Ирина создала WAV 143560 байт,
  Edge Светлана — MP3 22896 байт. Qt дошёл до EndOfMedia, файлы удалены;
  ошибки не зарегистрированы. Проверка на слух пользователем не выполнена.
- Реальный экранный захват: два монитора, на основном logical 1536×864 /
  pixels 1920×1080 (125%). Windows OCR распознал Hello world. Онлайн-перевод
  в этом запуске получил HTTP 429 от Google; успешный сетевой перевод не
  заявляется. Для HTTP 429 добавлено понятное сообщение, оригинал доступен.

Снимки: `docs/screenshots/background/`. Состояния маскота на них демонстрационные;
запись микрофона не использовалась. JSON native-report и speech-report хранят
результаты фактических проверок, capture-input — контролируемый снимок.

## Что требует ключей или ручной проверки

Реальное распознавание слова Eidos требует вашего ключа и моделей. Живая речь
через микрофон/Whisper, отключение физического устройства во время записи,
качество автоокончания речи и отсутствие самосрабатывания в вашей комнате
требуют ручной проверки оборудования. Модельные/бот-сценарии не повторялись;
их предыдущая логика сохранена и покрыта регрессионными тестами. Проверены
геометрия и захват на доступных экранах, но не каждый вариант DPI/перестановки
мониторов. Google зависит от сети и лимитов сервиса.
