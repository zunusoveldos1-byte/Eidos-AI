# Gesture control implementation plan

> Execution: superpowers:executing-plans, native in current session; user authorized routine decisions without repeated confirmation.

**Goal:** local hand tracking controls volume, media and cursor with explicit permission.
**Architecture:** latest-frame capture, Tasks detector, pure state machine, guarded Windows executor, GUI polling.
**Tech Stack:** Python 3.11, PyQt6, MediaPipe Tasks, OpenCV contrib (single cv2 wheel), numpy, PyCaw, Windows APIs.
**Spec:** ../specs/2026-10-11-gestures-design.md

## Constraints and review focus
No video recording/upload. No persisted control permission. No mouse clicks. Negative monitor coordinates use physical API. Thread-owned COM. Missing dependencies must not prevent startup. Review revoked permission during detection, partial hands, multiple hands, blocked capture and shutdown, DPI.
