# Eidos Workspace Implementation Plan

> Исполнение в текущей сессии по явному поручению пользователя, без повторного согласования обычных решений.

**Goal:** Восемь разделов и один переносимый персонаж при сохранении действующих операций.
**Architecture:** Переиспользовать виджеты форм и текущие контроллеры; новый MascotPlacement отвечает только за размещение единственного Mascot. Registry получает явный снимок/текст через TaskContext.
**Tech Stack:** Python 3.11, PyQt6, QtMultimedia, pytest.
**Spec:** ../specs/2026-10-11-workspace-design.md

- [x] Новые тесты навигации, единственности, переноса, старта, явного ввода экрана; исходные отказы подтверждены.
- [x] Sidebar, HomePage и реорганизация существующих форм: Диалог, Инструменты, Память, Настройки; параметры голоса перенесены без копирования.
- [x] InteractiveMascot и MascotPlacement, прозрачный настольный контейнер, перенос одного виджета, контекстное меню, клик/drag, положение/скрытие/снимок; подключён BackgroundControls.
- [x] Развёрнутый запуск и start_in_tray; явный предпросмотр камеры и освобождение устройства.
- [x] Общие инструменты OCR/перевода, только явный ввод; объяснение выбранного текста через существующую модель; границы обработки указаны.
- [x] 205 тестов, Qt smoke, снимки, GIF-демонстрация, отчёт и дорожная карта с критериями готовности.

Review focus: смена монитора во время drag; остановка/ошибка при переносе; скрытый персонаж при начале задачи; отсутствие камеры/трея; устаревший текст после нового снимка.
Изменения выполняются поверх существующего незакоммиченного проекта; автоматические коммиты не создаются.

Ruling: персонаж перемещается внутри выделенной полосы приложения — так он не перекрывает поля и кнопки страниц. Настольное окно свободно перемещается по мониторам.
Ruling: исправлено удержание MainWindow во время асинхронного закрытия — общий прогон выявил QThread, который мог уничтожаться до завершения озвучки.
Ruling: полный прогон выполняется вне песочницы — Windows asyncio зависает на локальных служебных сокетах даже без сетевого запроса; внешние сервисы тестами подменены.
Ruling: GIF составлен из кадров реальных Qt-виджетов — физический рабочий стол не записывался; это явно обозначено в отчёте.
