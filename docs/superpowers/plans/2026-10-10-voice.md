# Voice Implementation Plan

**Goal:** компактный голосовой режим по пользовательскому заданию.
**Architecture:** расширить существующие VoiceController, BackgroundControls,
SpeechQueue и WakeController; общий проигрыватель, GUI bridge для JonSnow.
**Tech Stack:** Python 3.11, PyQt6, numpy, Faster Whisper, Edge/SAPI, Porcupine.
**Spec:** ../specs/2026-10-10-voice-design.md

## Global Constraints
- Сохранять фон, трей, инструменты, JonSnow и память.
- Пауза продолжает тот же файл/позицию; Stop отменяет очередь и задачу.
- Нет фиктивных TTS стилей, OCR confidence или определения говорящих.
- Wake необязателен; UI координаты в логических пикселях.

## Review Focus
- Поздний результат после отмены должен удалиться, а не проиграться.
- Wake не должен слышать озвучку и её акустический хвост.
- Одинаковые намеренные запросы допускаются при новом ID записи.
- Пропуск onboarding переживает перезапуск каждого профиля.
- Отключённый экран возвращает виджет на доступный монитор.
