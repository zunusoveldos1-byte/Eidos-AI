# Локальное управление жестами

Пользователь поручил поэтапную реализацию без повторных согласований. Реализуем в текущем checkout, сохраняя существующие изменения.

Один OpenCV capture worker непрерывно обновляет слот последнего кадра. Второй worker использует Tasks HandLandmarker VIDEO и монотонные timestamp; отдельного Qt-захвата больше нет. GUI по таймеру забирает последний результат, поэтому сигналы не образуют очередь изображений. QImage владеет копией буфера.

Чистая геометрия классифицирует одну ведущую руку: три согнутых пальца + указательный/большой для громкости; пять открытых для медиа; только указательный для курсора. Размер ладони нормализует расстояние. Гистерезис, EMA, мёртвые зоны, удержание и повторная активация независимы от исполнителя. Потеря руки, свежести или разрешения сбрасывает состояние.

Windows executor создаётся в processing thread; COM там же. Громкость scalar, Play/Pause через Windows, курсор в физических координатах EnumDisplayMonitors/SetPhysicalCursorPos. Разрешение действий с блокировкой и generation token отзывает устаревшие результаты. Нет кликов. Глобальная клавиша Ctrl+Alt+G обязательна для включения действий, настройка отдельная от клавиш перевода.

Модель загружается только при явном включении камеры, с прогрессом, timeout, SHA256 и атомарной заменой. Сбой модели оставляет preview. Все параметры сохраняются; разрешение управления не сохраняется. Калибровка четырёх шагов без действий, с пропуском и сбросом.

Проверки: синтетическая геометрия, fake executors, lifecycle, буферы, stale-frame/authorization races, native модель и измерения, аппаратная камера если доступна. Без оборудования результат обозначается как непроверенный на реальной руке.
