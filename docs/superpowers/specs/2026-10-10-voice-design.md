# Упрощённый голосовой режим

Задание пользователя: обновить существующий PyQt6 Eidos, сохранив фоновые
контроллеры, трей, JonSnow, память и инструменты. Работа выполняется в текущем
checkout без повторного согласования технических решений.

Один проигрыватель и очередь SpeechQueue остаются владельцами звука. Центральная
кнопка начинает ввод, завершает запись или приостанавливает/продолжает тот же
QMediaPlayer. Отдельный Stop отменяет обработку, выделение и очередь. Отключение
микрофона не меняет позицию воспроизведения.

VoiceOrb — клавиатурно доступная кнопка с зелёным микрофоном. Волны записи
используют RMS микрофона; воспроизведения — QAudioBufferOutput, если доступен.
При отсутствии данных показывается спокойная индикаторная анимация. Пауза
неподвижна. Основной экран содержит статус и сворачиваемые текст/настройки.
Плавающее окно 360×470 логических px содержит тот же orb, последний ответ,
кнопки Stop, микрофона, настроек и возврата. Координаты ограничиваются доступными
экранами, включая смену их геометрии.

Вкладка активации отдельно включает Porcupine и его модели/ключ. Wake worker
хранит 1,5 секунды аудио и после детекции продолжает тот же поток до паузы или
лимита. Whisper получает целую фразу; удаляется только префикс имени Eidos.
Wake отключён при любом ответе, включая паузу звука, обработку и захват экрана.
Отсутствующие wake зависимости не влияют на ввод по кнопке.

Недорогая обработка записи: удаление DC, адаптивный порог RMS для сегментации,
Silero VAD Faster Whisper, предел 5–120 секунд. Неуверенные сегменты не
исполняются; слова внутри фразы не дедуплицируются. Дубли отсеиваются по ID
записи, а не тексту. Число говорящих не выводится из громкости.

Характер neutral/friendly/energetic меняет формулировки и темп поддерживаемого
TTS. Произвольные SSML стили Edge не доступны. Реплики об успехе добавляются
только к подтверждённым deterministic ToolResult. Имя берётся из профиля и
используется редко. Чтение оригинала/перевода использует полный текст.

GUI bridge передаёт команды выделения JonSnow и чтения в главный поток.
Отмена не исполняет поздние GUI запросы. Результат перевода отражается в голосовом
интерфейсе. OCR предупреждение показывается только при предоставленной низкой
confidence; Windows OCR не предоставляет её и никаких значений не выдумываем.

Профили выбираются вручную, имеют собственные agent settings, память и флаг
onboarding. Пропуск сохраняется; повторный опрос доступен в настройках.
Никакой биометрической идентификации.

Проверки: состояния/пауза/отмена/очередь, wake одной фразой и освобождение
микрофона, STT confidence/шум/повторы, JonSnow bridge и отмена, профили/onboarding,
DPI 1/1,5/2. Скриншоты и GIF являются воспроизводимой UI демонстрацией;
синтетические уровни в демонстрации помечаются, аппаратные проверки отдельно.
