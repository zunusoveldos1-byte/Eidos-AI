# Перевод выбранной области — 10 октября 2026

Оставлен только ручной захват области: кнопка → выделение мышью → локальный
OCR → онлайн-перевод → статический слой поверх исходного текста. Код
непрерывного перевода, опрос экрана, отслеживание окон, кнопки паузы и запуска
всего экрана удалены. Захват выполняется только после нажатия кнопки.

Сохранены 67 языков, автоопределение письменности, загрузка локальных моделей,
индикатор распознавания/перевода, отмена, повторный перевод снимка, копирование
результатов и снятие слоя. Размер шрифта определяется по исходным символам,
а не по длине перевода. Готовый слой кешируется в QPixmap.

Проверка настоящего сценария: python scripts/check_translation_native.py.
Тест использует контролируемую надпись Hello world, переводит её в Привет, мир,
затем повторно в Hallo Welt. Разные письменности проверяются командой
python scripts/check_multilingual_ocr.py --auto. Изображения остаются локальными;
Google получает распознанный текст для перевода.

При прокрутке или перемещении исходного окна нужно снять слой и выделить область
снова. По скриншоту нельзя гарантировать точное семейство шрифта; короткий или
смешанный текст может требовать явного выбора языка. Дополнительные OCR-модели
скачиваются при первом использовании. Фоновые worker завершаются штатно.

Проверено: 50 тестов проходят; настоящий сценарий захвата и повторного перевода Windows успешен. compileall успешен.

Горячие клавиши: Ctrl+Alt+T — захват, Ctrl+Alt+R — обновление прежней области,
Ctrl+Alt+X — снятие слоя/отмена. Настройки содержат редактируемые сочетания и
переключатель включения; они сохраняются в config.json. Windows RegisterHotKey
работает через Qt native event filter без опроса клавиатуры. При конфликте
сохраняются прежние регистрации; при закрытии все клавиши освобождаются.
Во время редактирования сочетаний регистрации временно приостанавливаются.

scripts/check_hotkeys_native.py проверил настоящие системные сочетания при
свёрнутом окне: захват и перевод, свою клавишу, повтор, снятие, освобождение
старой комбинации и отказ занятой комбинации с сохранением предыдущей.
Все проверки успешны. Для теста использованы собственные Ctrl+Alt+F8…F11;
Google получил только контролируемую строку Hello world.

С горячими клавишами проходят 64 теста. При вводе новой комбинации горячие
клавиши приостановлены только пока пользователь редактирует поле в активном
Eidos; переключение в другое приложение возобновляет действующие сочетания.

## Упрощённый раздел и новые функции

Компактные шаги, понятные названия кнопок и цветной статус заменили большую
справочную карточку. «Обновить эту область» делает свежий снимок там же по
кнопке или Ctrl+Alt+R; работает также из панели поверх экрана. Изменившийся
текст в тестовом окне Save changes переведён по свежему снимку. Фонового
опроса экрана и режима реального времени нет.

Исходный текст редактируется. «Перевести текст» отправляет исправленный текст
без повторного OCR. «Вставить текст» только заполняет поле: сама вставка ничего
не отправляет. «Скопировать перевод» копирует результат. Переключатель позволяет
оставить результат в Eidos или показать на экране. Языки и способ показа
сохраняются автоматически. Для исправленного текста прежние координаты
используются, только если число строк соответствует снимку; иначе результат
показан в карточке, чтобы не размещать его в неверном месте.

70 тестов проходят: настройки языков, исправления без OCR, вставка без отправки,
свежие пиксели в прежней области, отмена отложенного захвата, копирование и
предыдущие функции. Настоящие сценарии захвата/горячих клавиш Windows успешны.
