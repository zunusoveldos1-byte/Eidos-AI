# Результаты проверки — 9 октября 2026

Это отчёт первоначального голосового MVP. Последующая переработка UI и
актуальные 37 тестов описаны в [ui-verification.md](ui-verification.md).

Среда: Windows x86-64, локальный Python 3.11.17 в `.python`, окружение `.venv`.
Папка проекта изначально пуста, AGENTS.md и Git-репозиторий отсутствовали.

## Зависимости

PyQt6 6.11.0 / Qt 6.11.2, numpy 2.4.6, sounddevice 0.5.6,
faster-whisper 1.2.1, CTranslate2 4.8.2, edge-tts 7.2.8, pytest 9.1.1.
Полный снимок — requirements-lock.txt. Vision/OCR не установлены.
Опциональные голосовые движки импортируются при использовании; импорт eidos
или окна не импортирует faster_whisper/edge_tts/ctranslate2/onnxruntime.

## Что не подтверждено

Реальная запись выбранного микрофона и отказ доступа Windows не проверены на
физическом устройстве: они покрыты тестами на границе адаптера.
Whisper-модель не скачивалась, реальная точность STT и полный живой цикл
не проверены. На слух воспроизведение не подтверждено. CUDA не проверялась.
Нет замеров FPS или задержек. Текущий ресемплер линейный; его качество для
конкретного устройства также нужно оценить на реальной речи.

Закрытие во время записи, STT и TTS с подменёнными движками проверено реальным
QThread: окно ждёт работающий движок, поздний результат не воспроизводится,
временное аудио удаляется. Отмена TTS и удаление
частичного файла проверены тестом. При длительном скачивании/нативном вызове
Whisper окно может ожидать завершения: жёсткая отмена не реализована.

## Ограничения среды и исправленные ошибки

- Сетевая песочница не разрешает DNS PyPI: зависимости загружены разрешёнными
  командами вне песочницы в папку проекта.
- pytest tmp_path в перенаправленном системном TEMP получал отказ доступа:
  проверки выполнены с `--basetemp=.cache/...`.
- Даже `asyncio.run(asyncio.sleep(0))` зависает в ограниченной Windows-песочнице.
  Полная suite и TTS выполнялись вне неё; зависшие диагностические процессы остановлены.
- Qt offscreen на этой Windows не перечисляет системные шрифты (0 семейств),
  поэтому визуальный снимок сделан с настоящим Windows-плагином.
- Найдена и исправлена коллизия сигнала журнала с QObject.event.
- Найдена тестом и исправлена невозможность нового старта после поздней ошибки
  QtMultimedia, когда worker уже завершил работу.

Приложение не объявляется полностью проверенным до ручного живого сценария.
