# Ассистент Eidos

Существующие пять страниц и ручной голосовой цикл сохранены. Новый пункт
«Ассистент» содержит вкладки «Диалог», «Память», «Календарь», «Skills»,
«Подключения», «Модель», «Профиль». Не используется исполнение кода модели.

## Запуск в этой папке

```powershell
Set-Location 'C:\Users\Элдос\Desktop\Eidos'
& .\.venv\Scripts\python.exe -m eidos
```

Для команды без полного пути:

```powershell
$env:PATH = "$PWD\.venv\Scripts;$env:PATH"
python -m eidos
```

Зависимости при новой установке:

```powershell
py -3.11 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

Ollama — отдельный runtime. В подготовленной папке он размещён в
`.tools\ollama`; модели — `.cache\ollama-models`. Эти большие файлы не входят
в Python wheel. При переносе установите Ollama с официального сайта или
перенесите portable runtime и модели. Eidos подключается к работающему
локальному сервису; если он отсутствует, запрос свободного диалога запускает
известный portable / установленный Ollama на loopback. Модель автоматически
не скачивается. Кнопки запуска, загрузки и проверки — во вкладке «Модель».
Запущенный Ollama остаётся отдельным локальным процессом после закрытия GUI,
а модель выгружается после двух минут простоя. Нет автозапуска с Windows.

Ручная подготовка и измерение:

```powershell
& .\.venv\Scripts\python.exe scripts\prepare_local_model.py --model qwen3:4b-instruct-2507-q4_K_M
& .\.venv\Scripts\python.exe scripts\benchmark_agent.py
```

До загрузки UI показывает размер известных моделей и запрашивает согласие.
Для неизвестного тега нужно проверить размер в официальном каталоге. Скачивание
имеет лимит два часа в UI; обычная задача — 120 с, проверка модели — 180 с.

## Модель и оборудование

Диагностика измеряет CPU, RAM, свободный диск, display adapters, NVIDIA VRAM и
драйвер; серийные номера, UUID и сетевые идентификаторы не собираются и не
передаются в модель. Результат данного ноутбука: `hardware.json`. Наличие
NVIDIA-драйвера само по себе не доказывает offload: фактическая память GPU
загруженной модели проверяется через `/api/ps` и nvidia-smi.

Выбор для i5-12450HX / RAM 16 ГБ / RTX 3050 6 ГБ:

| Вариант | Вес на диске | Квантование | Контекст | Конфигурация |
|---|---:|---|---:|---|
| Основной Qwen3 4B Instruct 2507 | 2,5 ГБ | Q4_K_M | 4096 | GPU; Instruct без thinking |
| Облегчённый Qwen3 1.7B | 1,4 ГБ | Q4_K_M | 2048 | GPU предпочтительно; CPU допустим |

Точный основной тег — `qwen3:4b-instruct-2507-q4_K_M`. Общий тег
`qwen3:4b` при проверке оказался Thinking-версией 2507; параметр `think: false`
не превращает её в Instruct. Для коротких ответов выбран отдельный Instruct.

Whisper остаётся `base`, CPU int8. Большой контекст, несколько моделей и
будущая камера повышают расход памяти. При первоначальной проверке было
свободно только около 0,5 ГБ RAM; позже 1,59 ГБ. Это снимки состояния, не
постоянная характеристика. Приложение не закрывает сторонние программы.
Измерения скорости и памяти локальной модели сохраняются в
`agent-benchmark.json`; RSS рабочих наборов daemon + backend и VRAM
показываются отдельно. В этой сессии: первый ответ 5,745 с, объяснение Python
1,916 с, полный harness календаря 1,690 с; пик RSS 1050 MiB, размещение в GPU
2,96 GiB. Совместная работа с Whisper/камерой/OCR ещё не измерена.
Подробности и первая неудачная проба — `agent-verification.md`.

## Работа

1. Опрос «Чем вы занимаетесь?» допускает несколько профессий, необязательное
   имя, язык, задачи и отдельное согласие на память. Его можно пропустить;
   ответы меняются во вкладке «Профиль». Они не ограничивают функции.
2. В диалоге введите запрос. Простые команды времени / даты / Windows работают
   без LLM. «Открой Блокнот» / «Запусти Блокнот» работают без модели, если
   приложение с таким именем добавлено в разрешённый список. Свободное
   общение требует модели. Кнопка «Остановить» отменяет задачу.
3. Модель выбирает только зарегистрированные инструменты с JSON-аргументами.
   Валидация проверяет типы (bool не является integer), диапазоны, enum,
   обязательные поля и отсутствие лишних аргументов. Максимум 8 модельных
   шагов, до 4 вызовов в шаге. Повтор действия с побочным эффектом блокируется.
4. Результат проверяет конкретный адаптер: чтение фактической громкости,
   запись/чтение локального события или файла, ответ bot API. Без инструментов
   ответ помечается как текст модели. Неподтверждённый результат не становится
   успешным, даже если модель утверждает обратное.
5. Подтверждения изменений календаря и отправки показывают конкретные
   аргументы / получателя / текст в GUI. Закрытие окна отклоняет ожидающее
   подтверждение. После чтения недоверенных данных новое действие модели
   с побочным эффектом тоже требует подтверждения. Данные не меняют права.
6. Сетевые запросы ограничены таймаутом и размером; retry допускается только
   для чтения и ConnectionError. Действия Windows, записи и отправки не
   повторяются автоматически. Запрос Ollama выполняет AsyncClient внутри
   worker, его отмена прерывает ожидание headers и streaming. Другие сетевые
   read могут завершаться до 30 с; нативный парсер / COM-вызов не прерывается
   принудительно. Выполненные действия не откатываются.

## Документы и браузер

Файлы доступны только после выбора через диалог, права действуют до закрытия
доступа кнопкой или завершения приложения. Отдельно выбирается рабочая папка
для поиска и создания. Корень диска выбрать нельзя; выход за разрешённые
границы, неподдерживаемые расширения и файлы более 10 МБ запрещены. Не следует
выбирать папку с файлами, которые не хотите предоставлять ассистенту.

Чтение TXT/MD, DOCX, XLSX, PDF; создание текстовых документов в этих форматах.
Кнопки чтения и создания работают без LLM. При существующем имени всегда
создаётся новая версия. Редактирование означает создание нового текстового
содержимого: сложное оформление DOCX/PDF, макросы, формулы и диаграммы XLSX
не переносятся. XLSX создаётся из TSV как текстовые ячейки без формул.
Лимиты: до 12000 символов чтения, до 8000 символов записи, PDF до 20 страниц,
XLSX до 5 листов / 200 строк / 30 колонок; распакованный ZIP до 50 МБ.
Зашифрованный PDF не читается; скан без текстового слоя требует будущего OCR.

Поиск файлов ищет имена только в выбранной папке, максимум 3000 файлов / 100
совпадений. Поиск в интернете открывает DuckDuckGo или Bing, не выдаёт
выдуманные результаты поиска. Дополнительно подключается Brave Search API:
API key в Credential Manager, выбор Brave во вкладке «Модель», кнопка
проверки API. Он возвращает до 5 источников с URL / заголовком / описанием,
которые модель может изложить и дополнить чтением страниц. Без ключа этот
вариант отклоняется; DuckDuckGo/Bing не требуют ключа. Официальный API:
[Brave Search](https://brave.com/search/api/).
Для чтения конкретной публичной страницы
используется отдельный `web_read`: без скриптов, cookies и пользовательского
профиля; HTTP(S), до 2 МБ, запрещены локальные/служебные IP и такие redirects.
Браузерное управление страницей через Playwright пока не реализовано.

## Память и календарь

`%LOCALAPPDATA%\Eidos\memory.sqlite`: отдельно dialogue, profile, preference,
project, summary. FTS5 ищет максимум 5 релевантных записей; контекст ограничен
последними 6 сообщениями. После перезапуска при включённой памяти берутся до
3 последних диалогов, а не вся история. Facts добавляет пользователь с
источником и датой, модель не записывает догадки как project/preference.
Автоматические summaries являются ответами модели, а не проверенными фактами.

Память выключена по умолчанию. Можно просматривать, искать, редактировать,
удалять записи, очищать историю/всю память, отключать сохранение. «Разговор
без сохранения» не использует историю/FTS и не сохраняет новые сообщения.
Профиль в настройках отдельный: для удаления имени/задач очистите поля и
сохраните. Удаление памяти не удаляет календарь и данные защиты от повторной
отправки. Настройки — `agent.json`, пример `agent.example.json`, без секретов.

Локальный календарь поддерживает создание/просмотр/изменение/удаление,
IANA timezone (по умолчанию Asia/Bishkek), UTC внутри SQLite. Напоминания
проверяются каждые 30 с, только пока приложение открыто, включая события,
начавшиеся не более часа назад. Внешняя синхронизация — ещё не реализованный
адаптер `CalendarProvider`; токен сам по себе её не включит.

## Подключения и права

Telegram: bot token от BotFather, числовые user IDs и chat IDs. Discord:
официальный bot token, user/channel IDs, приглашение бота с View Channel,
Read Message History, Send Messages и Message Content Intent в Developer Portal.
Никаких личных аккаунтов, self-bot или извлечения cookies.

В «Подключениях» введите данные, сохраните, проверьте API, включите получение.
Сообщение допускается только при совпадении пользователя И канала со списками.
Пустые списки никому не дают доступ. Оба канала по умолчанию выключены.
REST polling раз в 5 с, когда worker свободен, до 20 сообщений за запрос;
Discord начинает с последнего сообщения, не проигрывает старую историю.
Вложения не принимаются (0 байт), текст до 2000 символов. Это текстовый
bot-адаптер, не полноценный Discord Gateway / менеджер медиа.

Удалённые диалоги не получают профиль, историю, FTS, файлы или календарь.
Windows capabilities отдельно разрешает пользователь; по умолчанию ни одной.
Входящая задача и исходящая доставка резервируются в SQLite до выполнения /
отправки. Неизвестный исход сетевого запроса не вызывает повторной отправки;
нужно проверить его вручную в канале. Даже ответ бота подтверждается в GUI.

Секреты — только Windows Credential Manager (явный WinVault backend keyring),
без fallback в plaintext. Есть удаление секрета. Поля очищаются после сохранения.
API-ошибки не выводят token URL; известные форматы ключей / секретных полей
фильтруются из памяти. Также блокируются точные значения четырёх ключей Eidos
из Credential Manager, а результаты чтения очищаются до передачи модели.
Это не универсальное распознавание любого произвольного
секрета: храните секреты именно в специальной форме, не в документах/диалоге.

OpenAI необязателен: введите свой API key и выберите provider во вкладке
«Модель». Ключ не входит в контекст. Пользовательский запрос и выбранные
профиль/память/документы тогда обрабатываются облаком. Без ключа вызов отклоняется.

## Ограничения первого этапа

Нет полного универсального desktop automation, автоматического запуска кода,
работы с Photoshop как редактором, сложной переразметки документов, внешнего
календаря, wake-word, Vision/OCR и фоновой записи микрофона. Skills честно
разделяют готовые инструменты, модельные советы, требующие подключения, и
нереализованные модули. Память не переобучает веса.
