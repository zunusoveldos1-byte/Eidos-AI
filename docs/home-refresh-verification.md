# Главная Eidos — 13 октября 2026

Проект использует Python 3.11 / PyQt6, не C#/.NET. Обновление выполнено в текущей архитектуре; существующие контроллеры, сервисы, ID разделов и команды сохранены. Предшествующие изменения рабочей папки не откатывались.

## Реализовано

- Палитра: фон `#081D18`, поверхности `#0D3025`, зелёный `#0D3B2C`, акцент `#25E6A1`, текст `#F2FAF6` / `#A9BDB5`.
- Главная: «Привет, я Eidos», короткий статус, ввод «Что сделать?», микрофон, отправка / Enter, три карточки. Подробности перенесены в подсказки.
- «Поговорить» использует текущий голосовой режим. «Перевести экран» запускает текущее выделение области. «Открыть приложение» предлагает Блокнот, разрешённые EXE и добавление EXE через существующий диалог. Ввод отправляется через существующий агент с его проверкой секретов и ограничениями занятости.
- Маскот справа — прозрачный RGBA-ресурс, подготовленный встроенным ImageGen по приложенному макету. Мини Эйдос и значок окна / трея используют тот же ресурс. Миниатюра рисуется из полного разрешения с учётом масштаба экрана.
- Локальные Comfortaa для логотипа / заголовка и Inter для интерфейса. Кириллица проверена через `QRawFont`; лицензия Comfortaa включена в сборку. Источник: https://github.com/google/fonts/tree/main/ofl/comfortaa.
- Волны движутся по периодической функции с циклом 16 секунд; лёгкое изменение формы имеет тот же период. Семь слабых линий / частиц исчезают до повторного появления. Маскот смещается на 0–4 px с периодом 5 секунд. Карточки поднимаются на 3 px, нажатие смещает их на 2 px. Появление героя: 240 ms, прозрачность и смещение 7 px.
- Декорации рисуются под интерактивными элементами; маскот и миниатюра пропускают мышь. Используется один таймер главной, около 30 кадров/с; размытия нет.
- Кнопка меню всегда находится в верхней полосе окна. Ctrl+B и кнопка меняют ширину контейнера меню за 280 ms; содержимое получает освободившееся место. Состояние `sidebar_collapsed` сохраняется в текущем `ConfigStore` и восстанавливается при новом запуске. Ctrl+B зарезервирован от глобальных команд, автоповтор отключён.
- Старые глобальные назначения Ctrl+B / Ctrl+8 при загрузке заменяются свободными комбинациями. Остальные параметры профиля сохраняются; конфликты с уже назначенными клавишами проверяются.
- «Отключить анимации» в настройках выключает декорации и анимированный переход меню. Учитывается Windows `SPI_GETCLIENTAREAANIMATION`, состояние перечитывается при активации окна. Главная останавливает таймер при скрытии, смене страницы и сворачивании окна.
- Камерный индикатор отражает реальный статус службы: включена, выключена, запуск, остановка, ошибка или отсутствие устройств. Нажатие открывает раздел камеры; само по себе устройство не включает.
- В узком окне компоновка становится вертикальной и доступна прокрутка; горизонтальной обрезки элементов нет.

Проверяется переключение / сохранение меню, рост области контента, переходы действий, запрос через агент, состояние камеры, уменьшенное движение, остановка таймера, отсутствие горизонтального переполнения и сохранение существующего поведения.

Итог последнего полного запуска: **83 passed in 16.15s**, код выхода 0. Проверены также два варианта миграции старых глобальных клавиш: со свободным стандартным назначением и с уже занятой стандартной клавишей. `git diff --check` для изменённых исходников прошёл без ошибок.

Снимки и геометрия проверены для 1674×940, 1200×800, 780×560 с меню и без него при масштабах 100%, 125%, 150%. Во всех 18 случаях горизонтальная прокрутка 0; ширина поля ввода не менее 289 px. В 780×560 доступна вертикальная прокрутка. Новый экземпляр окна восстанавливает скрытое меню.

Проверка кода независимым агентом не выявила оставшихся важных замечаний после устранения конфликта Ctrl+B, освобождения старых меню и восстановления состояния кнопки при ошибке сохранения.

## Границы проверки

- Физическая запись речи, полный OCR / сетевой перевод и ответ внешней AI-модели не проверялись. Проверены подключения к текущим действиям и реальная локальная команда агента.
- Физическое включение камеры не выполнялось; в среде нативной проверки устройство не найдено. Включение / выключение и ошибки индикатора проверены сигналами службы.
- Реальный запуск внешнего EXE из новой карточки не выполнялся; проверена передача команды существующему инструменту запуска.
- Остановка и возобновление анимаций проверены таймерами, снимки осмотрены. Длительная субъективная оценка плавности на разных GPU, 200% масштаб и другие мониторы не выполнялись.
- Собран Python wheel. Windows EXE / инсталлятор не создавались: в проекте не обнаружена существующая конфигурация их сборки.
