# Интерфейс Eidos по пяти референсам

Требования: исходное голосовое ядро сохраняется; пять страниц отдельно;
единое меню, QStackedWidget, 1200×800, layouts и прокрутка, локальные ресурсы.
Референсы пользователя задают внешний вид, примеры речи не становятся данными.

Решения: стандартная рамка Windows сохраняет resize/snap и клавиатурное управление.
Компактный режим — уменьшенное окно голосовой страницы со скрытым меню и кнопкой
возврата. В settings реализуем озвучивание, микрофон, модель, CPU/CUDA, выбор
двух русских голосов, always-on-top и отключаемую краткую анимацию маскота.
Автозапуск, светлая тема, другие языки интерфейса и смена акцента отключены с
пояснением. Изменения настроек применяются только кнопкой «Сохранить»; управление
микрофоном/озвучиванием на странице Голос сохраняется сразу и синхронизируется
с соответствующим полем настроек. Сброс спрашивает подтверждение.
