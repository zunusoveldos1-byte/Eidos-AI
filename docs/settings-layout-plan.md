# Компактные настройки Eidos

14 октября 2026. Реализуется точное распределение из задания пользователя.
Существующие поля переподчиняются новым формам без дублирования контроллеров,
сигналов, настроек и разрешений. Главная/голосовая композиция сохраняется.

1. Новый модуль settings_layout: компактные формы Общие, Модель, Подключения,
   Голос (две подвкладки), Перевод. Внутренние ссылки остаются совместимыми.
2. Динамическая видимость облачных/локальных полей и Edge/SAPI/Vosk/Whisper.
   Подсказки вместо больших описаний; общий save доступен для app-параметров.
3. Графитовые поля/popup и SVG-шестерёнка; светлая тема остаётся читаемой.
4. Проверки владельцев полей, переключения провайдера и сохранения параметров;
   Qt-снимки и scroll ranges при 1200×800/1920×1080, регрессионные тесты.

Малые окна и увеличенный масштаб шрифта сохраняют доступ через вертикальный
scroll fallback, вместо обрезания полей. Нет новых скачиваний/прав инструментов.
