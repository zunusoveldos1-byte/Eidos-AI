# Модернизация Eidos — 13 октября 2026

Исходный запрос: модернизировать существующий Eidos; сохранить главный экран,
страницу голоса, незакоммиченные изменения и данные. JARVIS-main исключён.
Работа выполняется в текущей ветке, поскольку новые worktree не содержат
пользовательских незакоммиченных изменений. Коммиты и сетевые публикации не нужны.

## Карта архитектуры

- `MainWindow`: стек страниц, настройки ConfigStore, навигация, завершение.
- `VoiceController` → `VoiceWorker` в QThread: запись, STT, маршрутизация.
- `BackgroundControls`: трей, handoff микрофона, WakeController, SpeechQueue.
- `AgentController` → AgentWorker: подтверждения, модель, инструменты.
- `AgentService`: разрешения, профили, SQLite Memory, контекст, провайдеры.
- `TranslationPage`: multi-monitor RegionSelector → QThread OCR/перевод → overlay.
- `GesturesPage` → CameraGestureService: discovery/capture/inference,
  один свежий кадр, отдельное временное разрешение на управление.
- `AppConfig`: атомарное JSON сохранение; AgentSettings и Profiles сохраняют
  существующее внутреннее окружение и согласие на сохранение данных.

## Этапы и проверки

1. Сохранить git status; полный baseline pytest с локальным basetemp;
   воспроизводимый benchmark без доступа к личной памяти и ключам.
2. Общая проверка секретов до перевода/TTS; отсутствие автоматической
   загрузки Whisper; честная диагностика Porcupine и локальных моделей.
3. Конфигурируемый Vosk/Faster-Whisper, один активный движок, ленивые модели,
   отмена между порциями, отдельные метрики, replay на предоставленном WAV.
4. Удалить переходы к диалогу/профилю/памяти; сохранить AgentService.
   Перенести необходимые разрешения файлов и текст документа в инструменты.
   Разделить локальный OCR и явный сетевой перевод; компактная камера.
5. Миграция памяти с происхождением/типом сведений и ограничением хранения;
   выводы модели не считаются подтверждёнными фактами. Старое согласие сохраняется.
6. Автозапуск HKCU, единственный экземпляр, реальные настройки маскота/темы,
   единая локализация с ключами, fallback и проверкой покрытия.
7. Регрессионные тесты, запуск/закрытие, визуальная проверка без изменения
   геометрии главной; отчёт о выполненном и внешних ограничениях.

## Документация

Context7 разрешён и прочитан для PyQt6, Qt 6, Vosk, Faster-Whisper,
Porcupine, Ollama. Windows Run — официальная Microsoft Learn документация.
Rustpotter: https://github.com/GiviMAD/rustpotter и rustpotter-cli;
Windows CLI есть, Python binding не подтверждён, преимущества не измерены.
30 мс — возможный бюджет конкретной обработки, а не обещание полного STT.

## Журнал решений

- Начальный тестовый запуск: sandbox TEMP с повреждённым Unicode; повтор
  с `--basetemp=.cache/modernization-baseline`.
- Секреты и персональная память не используются для проверки. Тестовые
  данные синтетические, ключи тестовых провайдеров фиктивные.
- Отсутствующие модели не скачивать незаметно; настройка разрешения на
  загрузку по умолчанию выключена. Vosk требует явно выбранного каталога.
- Сохранить существующее memory_enabled: удаление UI не означает
  автоматическое включение хранения вопреки прежнему выбору пользователя.
