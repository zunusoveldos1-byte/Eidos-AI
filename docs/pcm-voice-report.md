# Голос без временных аудиофайлов — 14 октября 2026

Микрофон: `sounddevice.RawInputStream`, 16 000 Гц, signed PCM16, один канал,
512 отсчётов (32 мс) на кадр. Колбэк только копирует байты в очередь максимум
32 кадра. Silero и Vosk выполняются в существующем голосовом QThread.
Те же PCM-байты поступают в Silero VAD и `Vosk.AcceptWaveform`, без
преобразования через float, контейнеры или диск. Silero внутри преобразует
PCM в float32-тензор, необходимый нейросети.

Преролл ограничен 320 мс. Переполнение отбрасывает команду целиком; текст из
повреждённого потока не отправляется модели. Автоматическое завершение фразы
после 0,65 секунды тишины сохранено; это ожидание конца речи входит в STT latency.
Постоянное прослушивание между ответами, ручное отключение и стоп-команды сохранены.
Устройство должно поддерживать 16 кГц / mono / int16; скрытого перехода на другую
частоту нет. Дополнительный локальный PTT-вход тоже захватывает raw PCM16.
Необязательный Whisper получает float32-массив в памяти, поскольку этого требует
его API. Он по-прежнему является пакетным распознавателем.

Озвучка: Edge-TTS использует `Communicate.stream()` вместо `.save()`.
Сжатый сетевой ответ ограничен 16 MiB и декодируется библиотекой miniaudio в RAM,
без FFmpeg. Edge присылает сжатый формат по своему протоколу: утверждать, что
его сетевой транспорт является PCM, нельзя. В приложении хранится `PCMAudio`.
Полностью локальный SAPI использует `SpMemoryStream` с форматом 18
(16 кГц / 16 bit / mono), без WAV-файлов.
Нативный `QAudioSink` читает PCM через RAM-устройство `QBuffer`; `QMediaPlayer`,
файловые URL и очистка временных файлов удалены. Пауза сохраняет позицию,
отмена освобождает буферы. Пример Gemini также использует память и miniaudio.

Веса Vosk/Silero загружаются из локальных ресурсов до захвата; чтение моделей
при инициализации необходимо. Аудиофайлы во время захвата, VAD/STT,
синтеза и воспроизведения не создаются. Настройки и обычные журналы приложения
не являются записью аудио. Общесистемные компоненты FFmpeg не удалялись.

Изменены `recorder.py`, `stt.py`, `tts.py`, `playback.py`, `speech.py`,
`controller.py`, `worker.py`, `local_input.py`; добавлены `pcm.py`, `vad.py`,
официальная ONNX-модель и лицензия. Обновлены голосовые зависимости,
asyncio-пример и проверки потоков/отмены/паузы.

Реальная проверка Windows: SAPI вернул 66 560 байт PCM, Vosk распознал
«проверка речи», Silero обнаружил речь. Среднее время Silero на кадр —
0,296 мс при параллельной проверке; предыдущий отдельный замер — 0,144 мс.
Обработка всей синтезированной фразы Vosk вместе с VAD заняла 495,16 мс;
это обработка готового аудио целиком, а не задержка финализации после речи.
Беззвучное нативное воспроизведение завершилось без ошибок.
Данные: `docs/audit-2026-10-13/checks/pcm-native.json`.
Живая проверка Edge-TTS вернула HTTP 403; сетевой сервис не подтверждён.
Для проверенной локальной озвучки доступен Microsoft Irina Desktop.
Живой микрофон и диалог с Ollama в этой проверке не запускались.
Проверка параметров устройства подтвердила поддержку микрофоном по умолчанию
PCM16 / 16 кГц / mono без запуска записи.

Окончательная проверка: **382 теста прошли за 113,47 секунды**.
Лог полного прогона: `.cache/pcm-suite.log`; `compileall` также прошёл.
Нативную проверку можно повторить из корня проекта:
`python scripts/verify_pcm_memory.py` (Windows, локальный Vosk и русский SAPI).
