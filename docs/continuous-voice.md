# Непрерывный голосовой режим

Центральный микрофон включает режим; повторное нажатие выключает его, отменяет задачу и очищает речь. Отдельные Stop и кнопка отключения микрофона убраны из интерфейса. При обработке центральная кнопка остаётся доступной для выключения. Выключение режима не сохраняется между запусками: старт безопасно выключен.

Причина подтверждённого сбоя в коде: ввод был одноразовым, ожидание начала речи ограничивалось пятью секундами, а после ответа новый цикл записи не запускался. Кнопка разрешения ввода не запускала захват. Теперь при включённом режиме ожидание речи продолжается, фраза завершается после 0,8 секунды тишины, после ответа и защитной задержки 0,7 секунды начинается новая запись без ключевого слова. Максимальная длительность самой команды сохранена. Ошибка устройства останавливает автоматический перезапуск и остаётся видимой.

После первого успешного открытия потока микрофон закрывается, произносится «Привет! Я Эйдос. Слушаю вас», затем запись возобновляется. Приветствие не повторяется на следующих циклах. При выключенной озвучке или ошибке TTS приветствие остаётся текстом. Собственная озвучка не записывается. Ключевое слово остаётся независимой настройкой.

Мини-окно сворачивается кнопкой в верхней панели в значок 64×64. Значок можно перетаскивать, нажатие раскрывает окно. Состояние режима сохраняется. Цвет и состояние микрофона синхронизированы; при захвате области JonSnow скрываются обе формы.

## Проверка

190 тестов прошли. Проверены переключение режима, однократность приветствия, возобновление, сворачивание и раскрытие; остальные сценарии записи, частоты, STT, инструментов и отмены остаются в полном наборе. Старые проверки ручного завершения каждой записи и паузы центральной кнопкой обновлены под новое управление.

Выбранное устройство: Realtek, вход 44 100 Гц, Windows ConsentStore user/machine Allow. Реальный поток принимал звук; отдельная проба системного микрофона дала 95 208 отсчётов моно 16 кГц, пиковый входной RMS 0,069, средний RMS 0,015. Настоящий локальный Whisper вернул расшифровку. Её соответствие речи пользователя не подтверждено; команда при диагностике не выполнялась. Это не доказательство успешного сценария «Приветствие → Открой блокнот → результат». Такой контролируемый живой сценарий ещё нужно проверить с пользователем. Доступ к микрофону есть; тестовую расшифровку в приложении не подставляли.
