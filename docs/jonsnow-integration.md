Автор локальных изменений: JonSnow (`doniadishov901-arch`). Изменения найдены
в распакованном Eidos, отдельно от вложенного чистого клона. Все 103 файла
сохранившегося ZIP побайтно совпадают с `57515aa` (Initial commit): это точная
база сравнения. До интеграции создана полная локальная резервная копия
(11 264 файла, 586 899 615 байт), каждый файл проверен по SHA-256.
Архив, окружение, локальные данные и резервная копия не входят в Git.

Ветка основана на актуальном `main` — `58d582dad7bba2b04be2fc2f2b9cf0b1f509ceb8`.
Вложенная прежняя ветка `codex/jonsnow-changes` совпадала с этим коммитом и
не содержала найденных локальных изменений. Исходники совместимы с Eidos,
поэтому интегрированы прямо в приложение; отдельного приложения нет.

## Добавленные функции

- Ручной захват области, локальный Windows OCR и Tesseract, 67 языков,
  определение письменности, онлайн-перевод распознанного текста через Google.
- Статический слой поверх исходного текста, обновление той же области,
  отмена и снятие слоя; исправление/вставка текста, копирование результатов.
- Сохранение языков и режима показа, редактируемые глобальные горячие клавиши
  с обработкой конфликтов и освобождением регистраций при закрытии.
- Доступ через боковое меню, главную страницу и `--page translation`.
  `--page assistant` открывает сохранённый ассистент из общего проекта.

## Согласование с main

Трёхстороннее сравнение выполнено относительно точной ZIP-базы. Новые файлы
агента, памяти, календаря, провайдеров, каналов и голосового harness сохранены.
Удалений файлов нет. Шрифт Inter и OFL сохранены.

Содержательные конфликты: README описывает обе системы; pyproject и lock
содержат зависимости обеих версий; MainWindow подключает обе системы и ждёт
завершения голосового, агентского и OCR-потоков перед закрытием. Навигация
сохраняет шесть страниц и Ctrl+6 для ассистента. Ctrl+1…Ctrl+6 запрещены как
глобальные клавиши перевода. UI-тест сохраняет проверку ассистента и проверяет
доступность перевода. Диагностика OCR перенесена в worker: GUI-поток Qt уже
инициализирует COM в другом режиме.

## Проверки объединённой версии

В отдельном Python 3.11.9 окружении установлены requirements-dev.txt.

- 112 тестов прошли с Qt offscreen и с настоящим Windows Qt.
- Новый regression-тест проверяет одновременную работу ассистента и OCR,
  отмену, ожидание завершения и освобождение горячих клавиш при закрытии.
- compileall и pip check успешны.
- Запуск и штатное закрытие `--page translation` и `--page assistant` успешны.
- check_translation.py --online: Hello world → Привет, мир.
- check_translation_native.py: реальный захват, OCR, слой и повторный перевод
  на немецкий (Hallo Welt) успешны.
- check_hotkeys_native.py: capture, custom_capture, repeat, dismiss, conflict
  успешны; проверена работа при свёрнутом окне.
- check_multilingual_ocr.py --auto: немецкий, кыргызский, арабский и японский
  распознаны с явным выбором языка; выполнены сценарии автоопределения.
- check_runtime.py: импорты, CPU compute types и обнаружение 8 входных устройств.

Первый запуск тестов в песочнице ограничивал Windows Credential Manager и
системные API; проверки повторены с разрешённым системным доступом.

## Ограничения

Автоопределение на коротком немецком примере выбрало Cyrillic, хотя текст
распознан верно; японский авто-режим может вставлять пробелы между символами.
Для точности используйте явный язык. Все 67 языков отдельно не проверены.
Слой статический: после перемещения исходного окна область нужно выбрать снова.
Google получает распознанный текст, сервис зависит от сети; изображения не
отправляются. Реальные модели Ollama/Whisper, запись речи и удалённые bot-каналы
в этой интеграции не проверялись; их интерфейсы проверены существующими тестами.
PR оставляется для review владельцем и автоматически не сливается.
