# Настройки Eidos: компактная структура

14 октября 2026. Существующие контролы и их подключения сохранены; формы
переподчинены новым карточкам в `eidos/ui/pages/settings_layout.py`.
Новые модели, сетевые вызовы, разрешения и изменения личных данных не добавлены.

## Распределение

| Вкладка | Содержимое |
|---|---|
| Общие | Windows startup, always-on-top, закрытие/запуск в трее, язык, тема/акцент, анимации, видимость/плавающий/закреплённый персонаж |
| Модель | Провайдер, локальная модель/адрес/контекст, поисковик, управление Ollama, проверка сервиса/ответа и диагностика |
| Подключения | Brave, OpenAI, Telegram, Discord, allowlists и четыре отдельных разрешения удалённого управления |
| Голос → Устройство и голос | Микрофон, refresh, озвучка, краткие ответы, голосовой hotkey, Vosk/Whisper, путь модели, чувствительность, лимит, вычисления, Edge/SAPI, голос, стиль, скорость/громкость, пример/stop и журнал |
| Голос → Активация голосом | Porcupine, ppn/pv, AccessKey, чувствительность и реальный статус |
| Экран и перевод | Переключатель горячих клавиш и Ctrl+Alt+T/R/X; прежние значения сохраняются |

OpenAI cloud model скрыта при Ollama; при OpenAI скрыты локальные параметры и
кнопки запуска/загрузки Ollama. Поля Edge/SAPI переключаются вместе с провайдером.
Путь Vosk скрыт при Whisper; Whisper model и CPU/CUDA скрыты при Vosk, который
использует CPU. Выбор модели не скачивает её. Подготовленная Vosk-модель остаётся
доступна для выбора. Запись настроек использует прежние ConfigStore/AgentService.

Разрешённые EXE перенесены к существующим инструментам Windows, с прежними
проверками доступа. OpenAI API key остаётся доступен в «Подключениях».
Секреты пустых полей сохраняются по прежним правилам. Длинные пояснения карточек
подключений перенесены в tooltip; длинные пути остаются редактируемыми полями.

Внешний дублирующий scroll убран. Все app-параметры (Общие, Голос, Перевод)
сохраняются общей кнопкой внизу, независимо от выбранной вкладки. Для Модели и
Подключений остаются собственные кнопки сохранения. Внутренний footer-slot старой
структуры сохранён совместимым; новый слот устанавливает окончательную видимость.
Нижняя полоса маскота не занимает место в настройках. Главная и отдельный
плавающий персонаж сохраняются, состояние и положение не сбрасываются.

## Стиль и иконка

Поля/списки/карточки: #0F1714, рамка #1E2923, hover #10B981.
Popup: #0B110F, выделение #164A35. #151E18 удалён из theme.py.
Светлая тема преобразует эту палитру в светлые фоны с тёмным текстом.
SVG шестерёнка имеет зубчатый контур, центральное отверстие и дополнительный
центральный акцент, использует currentColor для обычного/выбранного состояния.
Шрифты и отступы уплотнены только внутри настроек, главная геометрия не менялась.

## Проверка размеров

Снимки настоящих Qt widgets (offscreen), без чтения ключей и личной памяти:
`docs/screenshots/settings-layout/`. Полные scroll ranges в `geometry.json`.

| Размер окна | Общие | Модель | Подключения | Голос 1/2 | Перевод |
|---|---:|---:|---:|---:|---:|
| 1920×1080 | 0 | 0 | 0 | 0 / 0 | 0 |
| 1200×800 | 0 | 0 | 0 | 0 / 0 | 0 |
| 780×560 | 266 | 177 | 489 | 460 / 0 | 0 |

Числа — максимальный диапазон вертикальной прокрутки в логических пикселях.
Горизонтальная прокрутка равна 0 во всех проверенных случаях. В маленьком окне
колонки перестраиваются вертикально, доступ к параметрам сохраняется. Открытый
журнал событий или увеличенный системный шрифт могут потребовать scroll fallback.
Гарантия «на одной странице» не распространяется на произвольное разрешение/DPI;
проверенные стандартные размеры приведены явно.

Переключение всех пяти языков: runtime missing пуст, ключи каталогов совпадают,
локальный IPC и завершение потоков проверены `scripts/verify_modernization.py`.
Новый тест `tests/test_settings_layout.py` проверяет распределение контролов,
Ollama/OpenAI, Vosk/Whisper, Edge/SAPI и реальное сохранение перенесённых параметров.
Старые ожидания четырёх вкладок/внешнего scroll обновлены в существующих тестах.
Полный JUnit: `docs/audit-2026-10-13/checks/settings-layout.xml`.
Итоговый полный прогон: **320 passed in 69.04s**. После окончательной правки
контраста светлого акцента дополнительно прошли 4 проверки настроек/меню,
снимки и измерения геометрии обновлены. `git diff --check` без ошибок.

Первый общий прогон выявил старые UI-ожидания; они исправлены. Повтор также
выявил нестабильный тест HTTP deadline, который отдельно прошёл (4/4); сетевой
провайдер для этого редизайна не менялся. Отдельный тест возвращения плавающего
персонажа после захвата тоже прошёл; окончательный прогон сохранён в JUnit.
