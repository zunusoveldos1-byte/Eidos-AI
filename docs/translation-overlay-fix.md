# Исправление панели перевода — 14 октября 2026

Панель результата теперь получает клавиатурный фокус при показе. Ранее
`WA_ShowWithoutActivating` оставлял Esc в стороннем приложении, поэтому локальный
`QShortcut` панели не срабатывал. Сохранены QShortcut и резервный keyPressEvent;
Esc вызывает общий dismiss, который закрывает и deleteLater удаляет оба слоя.
Сам слой перевода остаётся прозрачным для кликов. Если пользователь впоследствии
переведёт фокус в другое приложение, локальный Esc принадлежит этому приложению;
кнопка «Убрать перевод» и глобальный Ctrl+Alt+X остаются доступны.

Показ результата больше не скрывает главное окно. Для чистого снимка Eidos
временно скрывается, затем восстанавливает прежнюю видимость без активации.
Если Eidos был скрыт перед захватом, он остаётся скрытым. Состояние сторонних
окон не изменяется. Код не вызывает showMinimized или принудительную минимизацию.

Панель: #0B110F, рамка #1E2923, радиус 10 px, мягкая тень с blur 28 px.
Текст #E2E8F0; кнопки #0F1714, hover/focus рамка #10B981 и текст #25E6A1.
Тень расположена внутри прозрачных отступов окна, чтобы не обрезаться.

Проверки: 28 тестов перевода, захвата и фонового режима прошли; те же 5 тестов
минимального захвата отдельно прошли на Windows Qt backend. Проверяются Esc,
отложенное удаление двух окон, сохранение видимости и отсутствие минимизации,
а также сохранение прежнего состояния при отмене захвата.

Итоговый общий прогон: 327 passed in 101.75s, basetemp=.cache/overlayverify.
Первый общий прогон дал 326 passed и ложное падение проверки автозапуска:
имя временной папки overlay-full-check содержало подстроку -c. После выбора
нейтрального имени весь набор прошёл без изменений кода автозапуска.
